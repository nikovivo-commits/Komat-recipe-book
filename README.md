## Komat Back Office

The [`ops/`](ops/) folder holds Komat's back-office app: stock control, supplier orders (sent by email), deliveries, bookings and the business inbox in one place. See [ops/README.md](ops/README.md) for what it does, how to connect Hypersoft, the reservation system and Gmail, and how to run it.
